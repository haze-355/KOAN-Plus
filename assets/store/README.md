# KOAN Plus ストア用画像

2026-09-07採用のK＋ロゴを使用したプロモーション画像です。濃紺の背景と白い文字を使い、コピーは「KOAN・CLEの授業・課題・連絡をまとめて確認」に統一しています。

| 用途 | 提出用PNG | 寸法 |
| --- | --- | --- |
| プロモーションタイル（小） | [promo-small-440x280.png](./promo-small-440x280.png) | 440×280 |
| マーキープロモーションタイル | [promo-marquee-1400x560.png](./promo-marquee-1400x560.png) | 1400×560 |

PNGはRGB各8ビット（24ビット）、アルファチャンネルなしです。同名のSVGは編集用原稿で、ロゴの図形と、マーキー用の画面画像を内包しています。テキストの書体はHiragino SansとHelvetica Neueです。見出しの「＋」は独立した図形で、KOANの字形の上下中央に揃えています。再書き出し時は書体・記号の位置・改行・寸法を確認し、RGB・透過なしで保存してください。

正式なロゴ原稿は [icon-source.svg](../icon-source.svg)、1024×1024のPNGは [koanpluslogo.png](../koanpluslogo.png) です。拡張機能用の16・32・48・128pxアイコンは `public/` にあります。

マーキーには1.6.0のローカルビルドのホーム画面を掲載しています。[撮影用デモ](../../scripts/store-demo/README.md)の合成データを使用し、画像内にも表示例であることを明記しています。実在する学務データ・認証情報は含まれていません。画像の作成とストアへのアップロード・公開は別の作業です。
