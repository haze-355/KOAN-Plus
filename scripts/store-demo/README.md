# ストア用の合成データデモ

`npm run demo:store` を実行し、表示された `http://127.0.0.1:4178` をデスクトップのブラウザで開きます。終了するときは、ターミナルで Ctrl+C を押します。

ビルドした `dist/` の画面を使い、授業・掲示・成績・課題を `fixture.mjs` の合成データに差し替えます。日時は2026年10月5日 10:00（日本時間）に固定しています。撮影するブラウザのタイムゾーンは `Asia/Tokyo` に設定してください。実アカウントのデータ、氏名、認証情報は使いません。

このサーバーだけが撮影用スクリプトを挿入します。`dist/` と拡張機能ZIPにはデモデータも日時固定処理も入りません。CSP の `connect-src 'none'` で外部API通信を禁止し、外部リンクのクリックと別窓の起動も停止します。サーバーはループバックアドレスだけで待ち受け、必要なビルド済みアセットだけを配信します。

掲示・シラバスのURLは製品側のリンク検証に合わせてKOANのホスト名を持ちますが、`/campusweb/__demo__/` 以下の架空パスです。公式サーバーへアクセスするためのサンプルではありません。実在のセッションURLで置き換えないでください。CLEのIDも `demo-` で始まる架空IDです。

## 撮影手順

1. ブラウザの表示領域を **1280×800 CSS px、倍率100%、デバイス倍率1** に設定する。ブラウザの枠や開発者ツールを含めず、PNGで保存する。
2. ホームの描画完了・最終更新 `10/5 10:00` を確認する。
3. 以下の5枚を撮影する。ページの先頭を使い、ポップアップや検索入力のフォーカスを残さない。
4. 各画像が1280×800であること、文字・グラフ・日本語フォントが読み取れることを確認する。

| ファイル名 | 画面・操作 |
| --- | --- |
| `01-home-light.png` | ホーム、ライトモード |
| `02-courses.png` | 授業 → 月2「データサイエンス入門」を選択、課題タブ |
| `03-notices.png` | 掲示、すべて・全ジャンル |
| `04-grades.png` | 成績、科目小区分を閉じた状態 |
| `05-home-dark.png` | ホーム → 右上のダークモード切替 |

読み込み直後の白画面や描画途中を撮らず、保存したPNGを実際に開いて確認してください。デモをリロードすると合成キャッシュとライトモードに戻ります。

生成した画像は `scratch/store-<version>/` などGit管理外に保存します。掲載時には「画面は合成データによる表示例です」と説明してください。撮影したバージョンのストア公開時に画像を差し替え、未公開機能を現在の公開版の仕様として掲載しないでください。

Chrome Web Storeの画像仕様は[公式ガイド](https://developer.chrome.com/docs/webstore/images)を参照してください。
