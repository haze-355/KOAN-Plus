# KOAN Plusの使い方

[READMEに戻る](../README.md)

このガイドはリポジトリの最新実装に対応しています。公開前の機能は [変更履歴](../CHANGELOG.md#unreleased) で確認できます。

## 最初の設定

拡張機能のアイコンからKOAN Plusを開き、利用規約とプライバシーポリシーを確認してください。自動ログインは任意です。設定せずに始め、後から「設定」で登録することもできます。

手動で利用する場合は、同じブラウザのKOAN・CLEでログインを完了し、KOAN Plusの右上にある「更新」を押します。認証画面が開いたら公式画面で操作を完了してください。

認証待ちがタイムアウトしても、開いている認証タブで操作を続けられます。次の同期では同じタブを再利用します。大学側の認証画面そのものが期限切れになった場合は、そのタブを閉じてから再度「更新」を押してください。

## ホームで締切と連絡を確認する

- **課題・締切**：CLEの課題とKOANのアンケートを締切順に確認できます。「それ以降」「期限未設定」「期限切れ」は見出しを押して展開します。提出済み・採点済みの課題は、授業画面で確認できます。
- **直近の休講・変更**：今後7日間の変更があるときに表示します。対応する授業がある行は、その授業の詳細へ進めます。
- **CLEの連絡**：授業ごとの未読メッセージ数と連絡事項を表示します。KOANの掲示とは別枠なので、掲示の件数に左右されず確認できます。
- **KOANのお知らせ**：最初は大学の「重要」指定がある掲示を表示します。「最新」に切り替えると、それ以外も含めて掲載開始日の新しい順に確認できます。

各欄の「さらに表示」で続きを確認できます。CLEの連絡事項に、取得日時から推測した未読マークを付けることはありません。

右側のカレンダーで日付を選ぶと、その日の授業に切り替わります。この日付選択は、中央の「課題・締切」をその日だけに絞り込む操作ではありません。

## 授業を選ぶ

「授業」を開き、時間割の科目を選びます。右側に教室・教員・曜日時限・変更情報が表示されます。「集中講義・曜日未定」にある授業も選べます。

| タブ | 使い方 |
| --- | --- |
| 課題 | 締切と提出状態を確認。期限切れ・提出済み・採点済みは展開して確認できます。課題のリンクはCLEの当該授業の成績・課題一覧を開きます。 |
| 連絡・掲示 | 選択した授業に関連するCLEの連絡とKOANの掲示をまとめて確認できます。本文は公式画面で開きます。 |
| 資料 | 選択した授業の資料一覧を取得し、個別または一括で保存できます。必要に応じて再取得できます。 |

授業名などから対応付けられなかった掲示が、このタブに出ない場合があります。大学全体の情報はホームや「掲示」でも確認してください。

タブにキーボードのフォーカスを置くと、左右矢印・Home・Endキーで切り替えられます。別の授業を選んでも、時間割のページから移動する必要はありません。

## 掲示を探す

検索欄とジャンル選択を、次の絞り込みと組み合わせられます。

| 絞り込み | 意味 |
| --- | --- |
| 重要 | 大学が重要指定した掲示。 |
| 要確認 | 未読・新着・件名などを手がかりに選んだ候補。自分への対応義務を示すものではありません。 |
| 未読 | 取得した情報で未読となっている掲示。 |
| 特典・謝礼 | 件名に無料・割引・謝礼などの記載がある掲示や、研究参加・学内サービスの候補。 |
| すべて | 保存済みの掲示全体。検索語やジャンルの条件は引き続き適用されます。 |

「特典・謝礼」は本文を自動で読んで判定する機能ではありません。本文にしか書かれていない特典は見つからない場合があり、「研究参加・謝礼未確認」の候補も含みます。金額、対象者、申込期限は公式の掲示本文で確認してください。

掲示のリンクを開くと、大学側で既読になる場合があります。KOAN Plusが本文を自動で先読みすることはありません。

## 成績を見る

上部で修得単位数と通算GPAを確認し、科目小区分を展開すると内訳を確認できます。学期GPAとその推移、履修成績も表示します。GPAはKOANに記録された値を使用し、不足データから通算GPAを推測しません。

成績がまだ取得されていない場合は右上の「更新」を押してください。更新中も別画面へ移動できます。

## 更新が止まったとき

1. 右上の「同期の詳細」を開き、どの情報が未取得・一部未取得・失敗なのかを確認します。最終成功時刻は、最後に取得できた時刻です。
2. ネットワーク接続を確認し、KOAN・CLEの公式ページでログインできているか確認します。
3. 同期の詳細にある「再試行」、または確認したい画面の「更新」を押します。通信間隔による待機がある場合は、KOAN Plusを表示したまま待つと再試行します。
4. 続く場合は拡張機能とKOAN Plusの画面を再読み込みし、再度更新します。

**未取得や取得失敗は「課題や掲示がない」という意味ではありません。** 保存済みデータを表示しているときは、公式画面でも最新の状態を確認してください。

キャッシュの削除は最初に試す必要はありません。削除すると、再取得できるまで保存済みの情報も読めなくなります。問題が続く場合は、エラー文、再現手順、拡張機能・ブラウザのバージョンを添えて [Issue](https://github.com/haze-355/KOAN-Plus/issues) で報告してください。個人情報や学務データは伏せてください。

## 設定とデータ管理

**自動ログイン**を有効にすると、保存したID・パスワードでのログインを補助し、画面を表示していてオンラインの間に古い学務情報を自動更新します。無効にすると定期的な自動同期も停止します。

**二段階認証**は別の任意設定です。登録情報を表示するとQRコード・手動入力用キー・保存されていれば一時解除コードを確認できます。キーの表示とコピーは別々に操作でき、モーダルを閉じて開き直すとキーは再び伏せ字になります。認証情報を同じ端末に保存するリスクを理解したうえで利用してください。

**データ管理**は初期状態で折りたたまれています。見出しを押すと、保存容量の確認とキャッシュの書き出し・削除ができます。

- 書き出し対象は学務情報のキャッシュです。ファイルには成績などの情報が含まれ得るため、公開Issueへ添付しないでください。認証情報・テーマ・同意情報は含まれません。
- キャッシュを削除しても、ログイン情報・二段階認証情報・テーマ・同意状態は残ります。
- ログイン情報と二段階認証情報は、それぞれの設定にある削除操作を使います。キャッシュの書き戻し機能はありません。

データの扱いは [プライバシーポリシー](../PRIVACY.md)、利用条件は [利用規約](../TERMS.md) を参照してください。
