## 短い概要

```text
大阪大学のKOAN・CLEの課題、締切、休講・教室変更、連絡・掲示、成績をまとめて確認できる非公式の拡張機能です。
```

この欄はストアの詳細説明ではなく、拡張機能のマニフェストにある `description` です。公式の上限は132文字で、上記はその範囲内です。[Manifest description](https://developer.chrome.com/docs/extensions/reference/manifest/description)

このリポジトリでは `package.json` の `description` を変更して `npm run build` を実行すると、`public/manifest.json` と配布用ビルドへ反映されます。`public/manifest.json` だけを編集するとビルドで上書きされるため、概要を変更する際は `package.json` を更新してください。2026-09-07に上記の概要を採用し、Chrome / Firefoxの両マニフェストへ反映しました。ストアへの反映には更新パッケージの提出・公開が必要です。

## 詳細説明：この枠内を貼り付け

```text
KOAN Plusは、大阪大学のKOANとCLEに分かれている学務情報を、まとめて確認できる非公式のChrome拡張機能です。課題の締切、休講・教室変更、連絡・掲示、成績をデスクトップのダッシュボードに表示します。

主な機能

・課題と締切を確認
CLEの課題とKOANのアンケートを締切順に表示。今日・今週の締切を確認し、期限未設定や期限切れの課題も展開して確認できます。

・時間割から授業の情報へ
授業を選ぶと、教室・教員・変更情報を右側に表示します。「課題」「連絡・掲示」「資料」のタブを切り替えながら、時間割を残したまま確認できます。CLEの資料は個別・一括で保存できます。

・CLEの連絡とKOANの掲示を整理
ホームではCLEとKOANを分けて表示し、掲示が多くてもCLEの連絡を探しやすくしています。授業画面では、その授業に関連する両方の情報をまとめて確認できます。

・重要な掲示や特典を探す
キーワード・ジャンル・未読などで掲示を絞り込めます。「重要」は大学が重要指定した掲示です。「特典・謝礼」では無料・割引・謝礼などの候補を件名から探せます。対象者や条件は掲示本文で確認してください。

・成績と修得単位を確認
修得単位数、KOANに記録されたGPAとその推移、科目ごとの成績や履修履歴を確認できます。

・保存済みデータをすぐに表示
前回取得した情報を表示しながら更新します。自動ログインを有効にすると、画面を表示していてオンラインの間に古い情報を自動更新します。手動更新にも対応し、取得状況や再試行は「同期の詳細」で確認できます。

データとログイン情報

学務情報と設定は利用中のブラウザに保存します。開発者のサーバーへの学務情報・認証情報の送信、広告、アクセス解析はありません。情報の取得や認証には大阪大学のサービスへ通信します。

自動ログインと二段階認証の補助は任意です。保存する認証情報は端末内で暗号化しますが、端末が侵害された場合まで保護するものではありません。二段階認証情報をログイン端末に保存すると認証の保護を弱める可能性があるため、大学の適用規則と利用規約を確認してご利用ください。

「お問い合わせ」はGoogle Formsを開き、拡張機能のバージョンとブラウザのUser-AgentをGoogleへ送信します。フォームへの入力・送信は任意です。

ご利用にあたって

KOAN PlusはMITライセンスのオープンソースで、大阪大学が提供・承認するサービスではありません。通常のKOAN・CLEの画面デザインは変更しません。課題の提出や履修登録、掲示・メッセージ本文の確認は公式サイトで行います。

大学システムの変更や通信状況により、情報を取得できない場合があります。重要な締切・提出状況・成績は公式画面でも確認してください。

使い方・ソースコード
https://github.com/haze-355/KOAN-Plus
```
