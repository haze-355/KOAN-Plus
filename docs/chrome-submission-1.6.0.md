# Chrome 1.6.0の審査提出記録

2026-09-07に、Chrome Web Storeへ1.6.0を提出しました。送信完了のメッセージと「審査待ち」の状態をデベロッパーダッシュボードで確認済みです。審査合格後に自動公開する設定を維持しています。提出時点の公開済みバージョンは1.5.0です。Firefoxへの提出は行っていません。

- 新しいK＋アイコン（16・32・48・128px）と日本語のパッケージ概要
- ストアのショップアイコン：[128px PNG](../public/icon-128.png)

プロモーション画像は24ビットRGB・透過なしのPNGです。マーキー内の画面は合成データによる表示例で、実在する学務データや認証情報は含みません。

## パッケージとソース

提出ファイルは `koan-plus-1.6.0-chrome.zip`。SHA-256は以下のとおりです。

```text
681809431b64d3c3bd4fdc3d4db0531e1e2af5631245f57eec7f101689f0d6f5
```

提出用には、mainを基点とする独立した作業ツリーへ採用済みのロゴ・概要・掲載画像だけを反映し、lockfileから依存関係をインストールしてビルドしました。本記録を追加したコミットが提出ソースを含みます。既存の `v1.6.0` タグはロゴ・概要変更前の履歴なので、この提出物の再現には本記録を含むコミットを使用してください。タグの付け替えは行っていません。

Node.js 22.23.2、npm 11.4.2を使用しました。

```sh
npm ci
npm run typecheck
npm test
npm run build
node scripts/build-zip.mjs dist koan-plus-1.6.0-chrome.zip
npm run test:ui
```

ZIPには拡張機能本体、manifest、4サイズのアイコン、ライセンス・第三者通知の計12ファイルが含まれます。実験用ロゴ、Affinityファイル、ストア用画像、テストデータ、開発環境設定は含まれません。ZIPのタイムスタンプ差異はソースの差異とは限りません。
