# 1.5.0 公開準備の確認記録

確認日：2026-09-05。対象は確認時点のソース、公開文書、依存関係、生成した配布ZIP。
ストア公開やGitHubへのpushは実施していない。

## 修正した点

| 対象 | 対応 |
| --- | --- |
| バージョン | package.json、lockfile、開発用・配布用manifestを1.5.0へ統一。ストアの確認時点の1.3.0と公開準備中の1.5.0を文書で区別 |
| 認証時の負荷 | KOANの認証待ちのポータル確認を5秒間隔へ変更。ログイン済みの即時確認、90秒の待機上限、1秒間隔のローカルなタブ閉鎖検出を維持 |
| 配布ライセンス | 本体MITライセンス、production依存関係のライセンス原文、inline SVGのLucide/Featherの通知をdistとZIPへ同梱。欠落したライセンスやlockfileとのバージョン不一致はビルドエラーにする |
| 公開文書 | 開発方針から内部会話IDと参照できない会話への依存を除き、現在のUI仕様への古い説明を修正 |
| データ説明 | CLE授業の連絡事項は本文も保存すること、CLEメッセージ・KOAN掲示本文とは別であることを日英のプライバシー説明へ追加 |
| 誤コミット防止 | `.env.*` を除外し、テンプレート用の `.env.example` 等は許可。生成物の既存除外を維持 |

第三者素材の出典・ライセンスは [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)、
具体的な同期挙動は [同期仕様](./sync-policy.md) を参照。

## 確認結果

- `npm run typecheck`：成功。
- `npm test`：17ファイル、144件成功。
- `npm run test:ui -- --workers=2`：既存の画面回帰テストを含め50件成功。新しいモバイル機能は追加していない。
- `npm run build`：成功。`node scripts/build-zip.mjs` でZIPを作成し、バージョン1.5.0、必要な拡張機能ファイル、本体・第三者ライセンスの同梱を確認。
- `npm audit --json`：照会時点で検出された既知の依存関係の脆弱性は0件（開発用を含む）。
- 確認時点の追跡対象・未除外ファイルに対する秘密鍵・代表的なAPIトークン・個人環境の絶対パスのパターン検査：該当なし。追跡対象・未除外の環境ファイル、ビルド、ログ、ZIP、テスト成果物もなし。
- Markdownの相対ファイルリンクと `git diff --check`：問題なし。
- MITライセンス、貢献手順、脆弱性の非公開報告案内、固定commitのGitHub Actions、読み取り権限のCI、Dependabot設定が存在することを確認。
- 本体の外部HTML表示にはDOMPurifyを使用し、認証用通知へのコード挿入はtextContentを使用する。認証・取得メッセージの送信元と通信先を検証する既存処理を維持。

## 検証の範囲

大学の実アカウントや実サーバーにはアクセスせず、合成応答とローカル環境で確認した。
Gitの全履歴の秘密情報監査、ストア審査、大学側の利用規則との適合性、すべての攻撃経路を
対象とする侵入試験を完了したという意味ではない。

KOANの通常更新の最大5系統の並列取得、100ページを超える未完了掲示ジャンルの再開、
サーバー指定の長い再試行待機などの残課題は [負荷調査](./server-load-audit-2026-09-05.md) に残す。
今回の認証間隔変更以外に、更新頻度や取得範囲を減らす変更は行っていない。
