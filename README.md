# KOAN Plus

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

[English](./README.en.md) · [Chrome Web Store](https://chromewebstore.google.com/detail/koan-plus/mpppnbfaakngenflnnoclhbckmjdngkm) · [使い方](./docs/user-guide.md) · [変更履歴](./CHANGELOG.md)

大阪大学の **KOANとCLEの情報をまとめて確認できる、非公式のブラウザ拡張機能**です。
課題の締切、休講・教室変更、連絡・掲示、成績を、デスクトップのダッシュボードで確認できます。
通常のKOANやCLEの画面デザインは変更しません。MITライセンスのオープンソースです。

このREADMEはリポジトリの最新実装を説明しています。各バージョンの公開状況は [変更履歴](./CHANGELOG.md) にまとめています。
現在のリポジトリのバージョンは **1.6.0** です。ストア公開済みバージョンとは異なる場合があります。

1.6.0にFirefox 140以降（デスクトップ）への対応を含めました。両ストアへは未提出で、Firefox向けの署名済み配布版はまだありません。審査提出済みのChrome版1.5.0とは別の配布物です。[ビルドと確認手順](./docs/firefox-verification.md)、[Firefoxへの公開手順](./docs/firefox-publishing.md)、[審査用の再ビルド手順](./BUILDING.md)を参照してください。

## できること

| 画面 | 確認できること |
| --- | --- |
| ホーム | 課題・アンケートの締切、直近の休講・変更、CLEの連絡、KOANのお知らせ。右側のカレンダーで日付を選ぶと、その日の授業を確認できます。 |
| 授業 | 時間割から授業を選び、教室・教員・変更情報と「課題／連絡・掲示／資料」を右側で確認。時間割を残したまま、別の授業へ切り替えられます。 |
| 掲示 | キーワード・ジャンルで検索。「重要」「要確認」「未読」「特典・謝礼」で絞り込めます。 |
| 成績 | 修得単位数、通算GPA、学期ごとのGPA、科目別の成績と履修履歴。科目区分を展開すると内訳を確認できます。 |
| 設定 | 任意の自動ログイン・二段階認証の設定。データ管理を展開すると、キャッシュの書き出し・削除ができます。 |

ホームではCLEとKOANを別々に表示し、KOANの掲示が多くてもCLEの連絡を探しやすくしています。
授業画面では、選択した授業に関連するCLEの連絡とKOANの掲示を同じタブにまとめます。
CLEの配布資料は、授業の「資料」タブから個別・一括で保存できます。ライト・ダーク表示にも対応しています。

**「重要」は大学が重要指定した掲示です。** 「要確認」と「特典・謝礼」は探すための補助分類で、個人にとっての重要性や特典の適用を保証するものではありません。条件や対象者は掲示本文で確認してください。

## 使い始める

1. [Chrome Web Store](https://chromewebstore.google.com/detail/koan-plus/mpppnbfaakngenflnnoclhbckmjdngkm)からインストールし、拡張機能のアイコンからKOAN Plusを開きます。
2. 初回の案内で利用規約とプライバシーポリシーを確認します。
3. 自動ログインを設定するか、設定せずに手動ログインで利用します。後から「設定」で変更できます。
4. 同じブラウザでKOAN・CLEにログインし、KOAN Plusの右上にある「更新」を押します。ログインを求められた場合は、公式の認証画面で完了してください。

課題の提出、履修登録、掲示・メッセージ本文の確認などは、各リンクから大学の公式画面へ進んで行います。
詳しい操作や困ったときの手順は [使い方](./docs/user-guide.md) を参照してください。

## 更新について

保存済みの情報は、次に開いたときもすぐに表示します。自動ログインが有効な場合は、KOAN Plusを表示していてオンラインの間、古くなった情報を自動で更新します。自動ログインを無効にしていても「更新」から取得できます。

取得中も画面を切り替えられます。「未取得」「一部未取得」「取得失敗」は、正常に確認できた0件と区別して表示します。更新できない場合も保存済みの情報を保持し、右上の「同期の詳細」で取得元ごとの状態と再試行を確認できます。

大学側の変更や通信状況によって更新に時間がかかることがあります。重要な締切・提出状況・成績は公式画面でも確認してください。開発者向けの通信間隔・再試行の仕様は [データ更新の仕組み](./docs/sync-policy.md) にまとめています。

## データとログイン情報

- 学務情報と設定は利用中のブラウザに保存します。開発者のサーバーへ学務情報や認証情報を送信せず、広告・アクセス解析・自動クラッシュレポートもありません。
- 学務情報の取得やログインのため、KOAN・CLE・大阪大学の認証サービスへ通信します。掲示やメッセージの本文を先回りして開くことはしません。
- 自動ログインと二段階認証の補助は任意です。保存する認証情報は端末内で暗号化しますが、暗号鍵も同じ環境にあるため、端末が侵害された場合まで保護するものではありません。
- 二段階認証情報をログインに使う端末へ保存すると、多要素認証による保護を弱める可能性があります。利用前に大学の適用規則と [利用規約](./TERMS.md) を確認し、自分で管理する端末で利用してください。
- 「お問い合わせ」はGoogle Formsを開きます。開いた際に拡張機能のバージョンとブラウザのUser-AgentがGoogleへ送信されます。フォームへの入力・送信は任意です。

保存するデータ、権限の用途、削除方法は [プライバシーポリシー](./PRIVACY.md) を参照してください。

## ソースからインストールする

Node.js `20.19.x`以降の20系、または`22.12.0`以上とnpmが必要です。
対応ブラウザはChrome 102以上です。他のChromium系ブラウザでは挙動が異なる場合があります。

```sh
git clone https://github.com/haze-355/KOAN-Plus.git
cd KOAN-Plus
npm ci
npm run build
```

1. Chromeで `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、生成された **`dist/`** を選びます。
3. 更新時は再ビルド後に拡張機能の「再読み込み」を押し、KOAN Plusの画面も再読み込みします。

プロジェクトのルートではなく `dist/` を選んでください。ルートのマニフェストは、誤って読み込んだ場合に開発ガイドを表示するためのものです。

## 開発・コントリビューション

不具合報告、機能の提案、翻訳、文書やコードの改善を歓迎します。
[GitHub Issues](https://github.com/haze-355/KOAN-Plus/issues) またはPull Requestを利用してください。
学内ID、認証情報、個人の成績やメッセージ本文を添付しないでください。脆弱性は公開Issueへ書かず [SECURITY.md](./SECURITY.md) に従って報告してください。

開発手順・必要なチェックは [CONTRIBUTING.md](./CONTRIBUTING.md)、目的と設計方針は [DEVELOPMENT.md](./DEVELOPMENT.md) にあります。

```sh
npm run dev                 # UIの開発サーバー
npm run typecheck           # 型チェック
npm test                    # 単体テスト
npx playwright install chromium  # UIテスト用ブラウザを初回のみ導入
npm run test:ui             # 合成データによるUIテスト
npm run build              # 拡張機能のビルド
npm run zip                # 配布用koan-plus.zipを作成
```

`npm run dev`だけでは、拡張機能の認証補助やタブ連携をすべて確認できません。実際の連携はビルドした拡張機能で検証します。`dist/`、`node_modules/`、テスト結果、ZIPなどの生成物はコミットしません。
